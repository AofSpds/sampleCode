# sampleCode

Standalone, reusable UI component examples. Each component lives in its own directory.

- [`cell-mergeable-grid/`](cell-mergeable-grid/): JSON table with group-key and non-key value rowspan merging, per-group radio selection, renderers, editors and Korean error messages.
- [`keyin-dropdown/`](keyin-dropdown/): jQuery UI autocomplete dropdown with optional free-text entry and a clear button.
